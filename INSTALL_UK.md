# Як завантажити та встановити MechaHub

Ця інструкція — для **Windows 10 або Windows 11, 64 біти**. Для готової програми Python і обліковий запис GitHub не потрібні.

## 1. Завантаж інсталятор

**[Натисни тут, щоб завантажити MechaHubSetup.exe](https://github.com/Mechaty17027/flosty/releases/latest/download/MechaHubSetup.exe)**

Посилання завантажує інсталятор останньої опублікованої версії. Дочекайся повного завершення завантаження; розмір файла показаний у списку Assets на GitHub.

Якщо ти вже на GitHub:

1. Відкрий [сторінку останнього релізу](https://github.com/Mechaty17027/flosty/releases/latest).
2. Прокрути вниз до **Assets** — це список файлів релізу.
3. Якщо список згорнуто, натисни **Assets**.
4. Натисни саме **MechaHubSetup.exe** та дочекайся завершення завантаження.

### Який файл обрати

| Файл | Для чого він |
| --- | --- |
| **MechaHubSetup.exe** | **Рекомендований варіант:** встановлення програми, ярлик у «Пуск», необов’язковий ярлик робочого столу та видалення через Windows. |
| **MechaHub.exe** | Готова програма для запуску без встановлення. Збережи її в окремій папці та запускай подвійним натисканням. |
| **update.json** | Опис оновлення, який читає MechaHub автоматично. |
| **Source code (zip / tar.gz)** | Вихідний код для розробників, які хочуть запускати або змінювати програму через Python. |

## 2. Встанови програму

1. Відкрий **Провідник Windows** і папку **«Завантаження»**. Якщо вибрав іншу папку під час завантаження, відкрий її.
2. Двічі натисни файл **MechaHubSetup.exe**.
3. Якщо інсталятор запропонує мову, обери **українську** та натисни **OK**.
4. Натискай **«Далі / Next»**. Типову папку встановлення можна залишити:

   ```text
   %LOCALAPPDATA%\Programs\MechaHub
   ```

5. За бажанням познач **«Створити ярлик на робочому столі»**. Ярлик у меню «Пуск» створюється автоматично.
6. Натисни **«Встановити / Install»** й дочекайся завершення.
7. Залиш позначку запуску MechaHub, якщо хочеш відразу відкрити програму, та натисни **«Завершити / Finish»**.

Встановлення виконується для поточного користувача й не потребує прав адміністратора.

## 3. Відкрий MechaHub

Натисни **«Пуск»**, введи **MechaHub** і відкрий знайдену програму. Якщо створив ярлик на робочому столі, можна двічі натиснути його.

Після запуску доступні програми, файли, мережа, вбудований браузер, курси валют і графіки ПК. Для сайтів та завантаження курсів потрібне підключення до інтернету.

### Перший вхід у навчання

1. У лівому меню відкрий **«Навчання»**.
2. Придумай пароль щонайменше з **8 символів** і введи його двічі.
3. Натисни **«Створити та відкрити»**.
4. Обери предмет і створи свій перший конспект. Кнопка **«Зберегти»** записує його у зашифроване сховище.

Збережи пароль: відновити зашифровані записи без нього неможливо. При виході з розділу змінений конспект зберігається, а доступ блокується.

## 4. Увімкни безоплатного ШІ — за бажанням

Цей крок потрібен для чату й допомоги ШІ з конспектами. Решта функцій MechaHub працює без Ollama.

1. Відкрий [офіційне завантаження Ollama для Windows](https://ollama.com/download/windows), завантаж і встанови Ollama.
2. У MechaHub відкрий **«Навчання»**, введи пароль та перейди до **«Безоплатний ШІ»**.
3. Натисни **«Запустити Ollama»**. Якщо її вже запущено, MechaHub перевірить підключення.
4. Обери **qwen3:4b** (завантаження приблизно 2,5 ГБ) або **qwen3:1.7b** для слабшого ПК (приблизно 1,4 ГБ). Для роботи також потрібна вільна RAM.
5. Натисни **«Завантажити вибрану модель»**. Потрібен інтернет; прогрес відображається в цій вкладці. Залиш розділ відкритим до повідомлення, що модель готова. Кнопка **«Зупинити операцію»** скасовує запит на завантаження; повторна спроба використовує збережені Ollama частини.
6. Перейди до **«ШІ-помічник»** і напиши запитання. Перший запуск моделі може тривати кілька хвилин.

Якщо модель уже встановлена, вибери її зі списку й натисни **«Перевірити підключення»**. Ці кнопки налаштування доступні з **0.6.1**. Для ручного налаштування залишено команду `ollama pull qwen3:4b` або `ollama pull qwen3:1.7b`, яку можна виконати у PowerShell.

Платний API-ключ не потрібен. Після завантаження модель працює локально; швидкість відповідей залежить від потужності ПК.

Якщо з’являється **«Ollama не знайдено»**, встанови її за посиланням у першому кроці. Якщо **модель не знайдена**, вибери її у вкладці налаштування й завантаж. При **нестачі пам’яті** закрий зайві програми або завантаж і вибери qwen3:1.7b. Після помилки чи зупинки текст питання залишається — натисни «Надіслати» для повтору. Якщо PowerShell не розпізнає `ollama`, відкрий нове вікно після встановлення.

## Оновлення та видалення

Починаючи з **0.6.0**, MechaHub перевіряє нові версії при запуску й кожні 6 годин, поки працює. Коли нова версія знайдена, у головному вікні з’являється пропозиція **«Оновити»**. У вікні **«Оновлення»** можна окремо ввімкнути автоматичну перевірку та завантаження.

1. Натисни **«Оновити»** у пропозиції або відкрий **«Оновлення»** у лівому меню.
2. Якщо файл ще не готовий, натисни **«Завантажити оновлення»** та дочекайся завершення перевірки.
3. Натисни **«Встановити й перезапустити»** та підтвердь дію.
4. Програма збереже відкритий конспект, закриється, оновить наявну копію й відкриється знову. Якщо конспект не вдалося зберегти, встановлення не почнеться.

Для встановленої програми зберігаються папка й ярлики. Для переносної копії зберігаються папка та назва EXE. Конспекти, пароль і налаштування залишаються на місці. Повністю видаляти програму перед оновленням не потрібно.

**Якщо у тебе ще 0.5.0:** один раз закрий її й запусти новий **MechaHubSetup.exe** з [останнього релізу](https://github.com/Mechaty17027/flosty/releases/latest) поверх наявної копії. Це додає новий механізм; далі оновлення виконуються через кнопку в MechaHub.

Видалення: відкрий у Windows **«Параметри» → «Програми»**, знайди **MechaHub** і вибери **«Видалити»**.

Конспекти й налаштування залишаються у `%APPDATA%\MechaHub`. Щоб зробити резервну копію конспектів, закрий MechaHub, натисни **Win+R**, введи `%APPDATA%\MechaHub` і скопіюй файл **study.vault** у надійне місце. Для його відкриття потрібен твій пароль.
