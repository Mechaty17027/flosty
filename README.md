# MechaHub 0.7.1 — WORKSPACE

Персональна програма для Windows 10/11 x64 на **Python + PySide6 + psutil**.

## Завантажити та встановити

**[⬇ Завантажити MechaHubSetup.exe — готовий інсталятор](https://github.com/Mechaty17027/flosty/releases/latest/download/MechaHubSetup.exe)**

1. Натисни посилання вище й дочекайся завершення завантаження.
2. Відкрий папку **«Завантаження»** на комп’ютері та двічі натисни **MechaHubSetup.exe**.
3. Якщо з’явиться вибір мови, обери **українську**. Натискай **«Далі / Next»**; папку встановлення можна залишити типовою.
4. За бажанням увімкни **ярлик на робочому столі**. Натисни **«Встановити / Install»**.
5. Після завершення натисни **«Завершити / Finish»**. Відкривай програму через **«Пуск» → MechaHub** або створений ярлик.

Python і обліковий запис GitHub для цього не потрібні. Ollama встановлюється окремо, якщо хочеш користуватися ШІ.

**[Повна інструкція з поясненнями та першим запуском](INSTALL_UK.md)** · [Сторінка релізів і всі файли](https://github.com/Mechaty17027/flosty/releases/latest)

На сторінці релізу файл **MechaHubSetup.exe** знаходиться внизу, у списку **Assets**. Якщо список згорнуто, натисни його назву. **MechaHub.exe** — варіант для запуску без встановлення; **Source code** призначений для розробників, а **update.json** використовує сама програма для оновлень.

- **Просте спілкування:** у навчанні є окрема кнопка загального чату. Мова відповіді визначається за запитанням або вибирається вручну. Історія цього режиму відокремлена від НМТ й конспектів.

## Налаштування навчального ШІ — від 0.6.1

У вкладці **«Безоплатний ШІ»** можна запустити встановлену Ollama й завантажити вибрану модель з індикатором прогресу. У чаті є кнопка налаштування та зрозумілий опис помилки. Після помилки або зупинки запитання залишається в полі; для повтору натисни **«Надіслати»**. Перший запит може тривати кілька хвилин на повільному ПК.

## Оновлення всередині програми — від 0.6.0

MechaHub автоматично перевіряє GitHub при запуску й кожні **6 годин**, поки працює. Коли є нова версія, у головному вікні з’являється пропозиція **«Оновити»**. Автоматичне завантаження можна ввімкнути або вимкнути окремо у вікні «Оновлення».

1. Натисни **«Оновити»** у пропозиції або відкрий **«Оновлення»** в лівому меню.
2. Якщо файл ще не завантажено, натисни **«Завантажити оновлення»** й дочекайся перевірки.
3. Натисни **«Встановити й перезапустити»** та підтвердь дію.
4. MechaHub збереже конспект, завершить свої фонові завдання, оновить наявну копію й відкриється знову.

Встановлена програма оновлюється в тій самій папці. Переносна копія замінює свій поточний EXE зі збереженням назви. Конспекти, пароль, ярлики й налаштування залишаються на місці. Файли перевіряються за SHA-256; у разі невдалого встановлення або запуску зберігається попередня копія.

**Перехід із 0.5.0:** один раз запусти новий **MechaHubSetup.exe** поверх наявної програми. Видалення попередньої версії не потрібне. Починаючи з 0.6.0 наступні оновлення встановлюються зсередини MechaHub.

## Нові можливості у 0.5.0

- **Навчання та конспекти**: чотири предмети НМТ — математика, історія України, англійська й українська мови. Окремі вкладки для записів, ШІ, джерел і налаштування.
- Пароль створюється при першому вході. Конспекти зберігаються локально з AES-GCM шифруванням; пароль не записується. Перехід між розділами зберігає записи та розблокований сеанс. Кнопка «Заблокувати» або закриття програми очищує доступ.
- **Безоплатний локальний ШІ через Ollama**: чат для підготовки, пояснення тем і пропозиції структури та правок. Правки застосовуєш сам; Ctrl+Z скасовує заміну. Інструкція налаштування є в програмі.
- Джерела з усіх предметів: безоплатні курси [iLearn](https://ilearn.org.ua/) та матеріали [УЦОЯО](https://testportal.gov.ua/). Посилання відкриваються у вбудованому браузері.
- **Валюти**: популярні USD, EUR, GBP, PLN, CHF, курси у гривнях, калькулятор між валютами та графік за 30 днів. Дані від [НБУ](https://bank.gov.ua/ua/open-data/api-dev), із датою курсу. Банківські курси купівлі/продажу та комісії можуть відрізнятися від офіційних.
- **Графіки ПК**: історія процесора й RAM, швидкості читання/запису диска та приймання/відправлення даних. Вимірювання виконуються під час перегляду розділу.
- GitHub автоматично збирає Windows-інсталятор, файл для запуску без встановлення та перевірений опис оновлення.

## Де зберігаються дані

Програма встановлюється для поточного користувача без прав адміністратора. Конспекти й налаштування зберігаються у `%APPDATA%\MechaHub`; видалення програми через інсталятор залишає ці файли.

## Налаштувати безоплатного ШІ

1. Встанови [Ollama для Windows](https://ollama.com/download/windows).
2. У MechaHub відкрий **«Навчання» → «Безоплатний ШІ»**, натисни **«Запустити Ollama»**.
3. Обери **qwen3:4b** (приблизно 2,5 ГБ) або **qwen3:1.7b** для слабшого ПК (приблизно 1,4 ГБ) та натисни **«Завантажити вибрану модель»**. Дочекайся повідомлення, що модель готова, й відкрий **«ШІ-помічник»**.

Якщо модель уже встановлена, достатньо перевірити підключення та вибрати її зі списку. Для ручного налаштування у програмі залишено команду `ollama pull`.

MechaHub використовує лише локальні моделі та адресу `127.0.0.1:11434`, без API-ключа й оплати запитів. Швидкість і якість відповідей залежать від моделі та ПК. ШІ не відкриває навчальні посилання самостійно: звіряй відповіді з джерелами. Частина вправ iLearn потребує безоплатної реєстрації на платформі. У списку є матеріали НМТ-2026; актуальні вимоги до наступного року перевіряй на УЦОЯО.

Збережи пароль навчання: без нього розшифрувати конспекти неможливо. Для резервної копії закрий програму й скопіюй `%APPDATA%\MechaHub\study.vault`.

## Запуск із вихідного коду (для розробників)

1. Розпакувати ZIP повністю, наприклад у `D:\MechaHub_v0.3.0`.
2. Якщо ще немає Python — встановити **Python 3.10+** з https://www.python.org/downloads/ (Windows 10/11).
3. Один раз запустити **`INSTALL_FIRST.bat`** (з інтернетом) — створиться ізольоване оточення `.venv` з бібліотеками.
4. Запустити **`RUN_MECHAHUB.bat`**. Якщо щось не працює — `RUN_DEBUG.bat` і надіслати текст помилки.
5. Відкрити **«Мережа» → «Розпочати SPEED TEST»**.

Конфігурація попередніх версій сумісна: ярлики залишаються у `%APPDATA%\MechaHub\config.json`. Якщо встановлена v0.2, нову версію краще розпакувати в нову папку — не затирати файли під час роботи програми.

## Важливі технічні примітки

- Це **не вбудований Speedtest by Ookla**; графіка власна, а швидкості приблизні та вимірюються до Cloudflare. Сервер, маршрут, Wi-Fi, антивірус та інші програми впливають на результат.
- **Обсяг тесту** обмежений: не більш ніж 64 МіБ на скачування та 24 МіБ на віддачу (плюс невеликий службовий трафік). Не варто запускати через дороге мобільне з’єднання.
- **Packet loss** — відсоток ICMP-запитів, на які не отримано відповіді. Звичайний ping не дозволяє локалізувати окремо втрати на вхідному та вихідному маршруті.
- **Вхідні/вихідні пакети** — загальні лічильники мережевого адаптера за період тесту, не окреме підтвердження успішності проходження пакетів через інтернет. Лічильники `dropin`, `dropout`, `errin`, `errout` можуть бути недоступними драйверу.
- Якщо ICMP блокується або Cloudflare недоступний, деякі показники будуть «—» із поясненням. Немає вигаданих результатів.
- Кнопка тесту **добровільно ініціює інтернет-запити** до Cloudflare; локальна інформація про ярлики туди не надсилається. Браузер звертається до відкритих сайтів, а оновлення — до заданого джерела та посилання на реліз. Телеметрії MechaHub немає.

## Розробка

- Перевірка логіки: `python -m unittest discover -s tests -v`.
- Збирання `.exe` з Windows: `BUILD_EXE.bat` (PyInstaller, файл у `dist`).
- У підготовленому локальному середовищі: `.venv\Scripts\python.exe -m unittest discover -s tests -v`.
- Перевірено на Windows із Python 3.12, PySide6 6.12.0 та psutil 7.2.2: логіку, Qt-потоки, сценарії запуску і відображення вікон. Мережеві тести ізольовані та використовують підставні відповіді.
- Після зупинки HTTP-запит може завершувати поточне очікування сокета до 2 с; пошук DNS залежить від ОС. Вікно закривається після завершення фонового потоку.

Всі інші функції v0.2 збережено: моніторинг ПК, список установлених програм, власні ярлики, сортування файлів з попереднім переглядом.
