# MechaHub 0.4.0 — WORKSPACE

Персональна програма для Windows 10/11 на **Python + PySide6 + psutil**.

## Новий інтерфейс у 0.4.0

- Фіолетові, бірюзові та теплі акценти замість однакових синіх блоків.
- «Огляд» містить короткі показники й швидкий запуск; деталі ПК винесено в «Система та процеси».
- Справжні іконки EXE, ярликів і папок у сітці програм; назви й шляхи доступні в підказках, при виборі та в окремому режимі керування.
- «Мережа» поділена на «Швидкість», «Якість зв’язку» та «Пакети».
- Вбудований браузер із вкладками, адресним рядком і навігацією.
- Окреме вікно оновлень: історія змін, перевірка й автоматичне завантаження нової версії з перевіркою цілісності.
- Підготовлено GitHub Actions для тестів і публікації Windows-релізів. Підключення сервера: [GITHUB_SETUP_UK.md](GITHUB_SETUP_UK.md).

Номер програми — `0.4.0`; ім’я існуючої папки збережено. Браузер запускає свій рушій при першому відкритті вкладки «Інтернет». Джерело оновлень потрібно налаштувати після публікації першого релізу GitHub.

## Покращення у 0.3.1

- Пошук у власних ярликах, перейменування та ручне додавання програм або файлів.
- Пошук установлених програм працює у фоновому потоці, з повідомленням про завантаження та помилки.
- Якщо налаштування не вдалося зберегти, список у вікні залишається без змін. Запис використовує окремий тимчасовий файл і атомарну заміну.
- Сортування перевіряє стан файлу після попереднього перегляду, враховує Windows junctions і не перезаписує файл, що з'явився одночасно з переміщенням.
- Зупинка мережевого тесту перериває ping; HTTP-запити мають коротші таймаути й обмеження часу та обсягу. Часткові результати позначаються `≈`, а фактично передані тестові дані показуються у МіБ.
- Надійніший пошук програм у реєстрі та перевірки в сценаріях запуску `.bat`.

Що саме було змінено, як реалізовано й перевірено: **[CHANGES_UK.md](CHANGES_UK.md)**.

## Що нового у 0.3.0

- Окрема вкладка **«Мережа»** в лівому меню.
- Великий **анімований спідометр**: рухома стрілка та поточний показник у Мбіт/с, окремі етапи Download та Upload.
- Тестування **реальної швидкості інтернету** за допомогою HTTPS-запитів до Cloudflare (`speed.cloudflare.com`).
- **Ping, jitter і packet loss** до `1.1.1.1` (ICMP, 10 проб).
- **Вхідні/вихідні пакети** з активного мережевого адаптера, а також помилки й відкинуті пакети за час вимірювання.
- Можливість зупинити тест; мережеві запити виконуються у фоновому потоці й не блокують інтерфейс.

## Встановлення та запуск

1. Розпакувати ZIP повністю, наприклад у `D:\MechaHub_v0.3.0`.
2. Якщо ще немає Python — встановити **Python 3.10+** з https://www.python.org/downloads/ (Windows 10/11).
3. Один раз запустити **`INSTALL_FIRST.bat`** (з інтернетом) — створиться ізольоване оточення `.venv` з бібліотеками.
4. Запустити **`RUN_MECHAHUB.bat`**. Якщо щось не працює — `RUN_DEBUG.bat` і надіслати текст помилки.
5. Відкрити **«Мережа» → «Розпочати SPEED TEST»**.

Конфігурація попередніх версій сумісна: ярлики залишаються у `%APPDATA%\MechaHub\config.json`. Якщо встановлена v0.2, нову версію краще розпакувати в нову папку — не затирати файли під час роботи програми.

## Важливі технічні примітки

- Це **не вбудований Speedtest by Ookla**; графіка власна, а швидкості приблизні та вимірюються до Cloudflare. Сервер, маршрут, Wi-Fi, антивірус та інші програми впливають на результат.
- **Обсяг тесту** обмежений: не більш ніж 64 МіБ на скачування та 24 МіБ на віддачу (плюс невеликий службовий трафік). Не варто запускати через дороге мобільне з’єднання.
- **Packet loss** — відсоток ICMP-запитів, на які не отримано відповіді. Звичайний ping не дозволяє локалізувати окремо втрати на вхідному та вихідному маршруті.
- **Вхідні/вихідні пакети** — загальні лічильники мережевого адаптера за період тесту, не окреме підтвердження успішності проходження пакетів через інтернет. Лічильники `dropin`, `dropout`, `errin`, `errout` можуть бути недоступними драйверу.
- Якщо ICMP блокується або Cloudflare недоступний, деякі показники будуть «—» із поясненням. Немає вигаданих результатів.
- Кнопка тесту **добровільно ініціює інтернет-запити** до Cloudflare; локальна інформація про ярлики туди не надсилається. Браузер звертається до відкритих сайтів, а оновлення — до заданого джерела та посилання на реліз. Телеметрії MechaHub немає.

## Розробка

- Перевірка логіки: `python -m unittest discover -s tests -v`.
- Збирання `.exe` з Windows: `BUILD_EXE.bat` (PyInstaller, файл у `dist`).
- У підготовленому локальному середовищі: `.venv\Scripts\python.exe -m unittest discover -s tests -v`.
- Перевірено на Windows із Python 3.12, PySide6 6.12.0 та psutil 7.2.2: логіку, Qt-потоки, сценарії запуску і відображення вікон. Мережеві тести ізольовані та використовують підставні відповіді.
- Після зупинки HTTP-запит може завершувати поточне очікування сокета до 2 с; пошук DNS залежить від ОС. Вікно закривається після завершення фонового потоку.

Всі інші функції v0.2 збережено: моніторинг ПК, список установлених програм, власні ярлики, сортування файлів з попереднім переглядом.
