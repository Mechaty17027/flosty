MECHAHUB v0.3.0 — ПЕРША ВЕРСІЯ ІЗ SPEED TEST
===============================================

1. Розпакуй увесь архів у нову папку, не поверх відкритої старої версії.
2. Якщо потрібно, встанови Python 3.10 або новіший.
3. Запусти INSTALL_FIRST.bat (потрібен інтернет).
4. Запусти RUN_MECHAHUB.bat.
5. У меню зліва обери «Мережа», далі «Розпочати SPEED TEST».

НОВИЙ РОЗДІЛ «МЕРЕЖА»
---------------------
• Спідометр зі стрілкою для швидкості Download і Upload у Мбіт/с.
• Ping, jitter, packet loss до 1.1.1.1.
• Вхідні/вихідні пакети мережевого адаптера та помилки/відкидання.
• Кнопка переривання перевірки.

ВАЖЛИВО
-------
• Тест використовує Інтернет: максимум 64 МіБ завантаження +
  24 МіБ відправлення (плюс невеликий службовий трафік).
• Швидкість вимірюється до Cloudflare, а не до офіційного Ookla Speedtest.
• Вхідні/вихідні пакети — статистика цілого мережевого адаптера,
  а не вимір втрат у кожному напрямку.
• Окремий процент втрат на виході та вході ping визначити не може.
• Деякі провайдери блокують ICMP; тоді будуть пропуски результатів.
• Тести мережі починаються ЛИШЕ після натискання кнопки користувачем.
• Програма не потребує прав адміністратора.

ЯКЩО НЕ ЗАПУСКАЄТЬСЯ
-------------------
Запусти RUN_DEBUG.bat. Зроби скриншот помилки й надішли його в чат.

ВАЖЛИВО ПРО ФАЙЛИ
-----------------
• Сортування файлів в «Файли» змінює лише файли в обраній папці,
  завжди після підтвердження.
• Для першого випробування використовуй тестову папку з копіями файлів.
• Видалення через MechaHub не виконується.

ЗБЕРЕЖЕННЯ СПИСКУ ПРОГРАМ
-------------------------
%APPDATA%\MechaHub\config.json

Готовий EXE: запусти BUILD_EXE.bat на Windows, знайдеш у dist\.
