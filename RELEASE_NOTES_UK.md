# MechaHub 0.7.1

- Додано МІНІ-ФП54.01 та IKC-E810T: тепер у касовому довіднику 10 моделей.
- Офіційні фото та мініатюри всіх моделей включено в програму; інтернет для перегляду не потрібен.
- Текст упорядковано: окремі вкладки «Характеристики», «Помилки та рішення», «Джерела».
- 38 описів повідомлень і первинних перевірок: пояснення, кроки оператора, рекомендація сервісу та офіційне джерело.
- Позначено версії ПЗ, відмінності модифікацій і коди HTTP/JSON API MG. Для Exellio доступні первинні перевірки; точну офіційну таблицю кодів поки не знайдено.
- Пошук знаходить моделі за скороченими назвами та повідомленнями про помилки.
- Оновлення встановлюється з MechaHub 0.6.0 і новіших зі збереженням даних, без ручного видалення.
