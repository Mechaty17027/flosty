# MechaHub 0.7.0

- Просте спілкування з ШІ: окремий режим, історія й чернетка без прив’язки до НМТ.
- Автоматична мова відповіді та ручний вибір української, англійської, польської, німецької, французької або іспанської.
- Виправлено англійські службові міркування Qwen3: до чату потрапляє лише кінцева відповідь.
- Пароль навчання вводиться один раз за сеанс. Перехід між розділами зберігає доступ; ручне блокування та закриття очищують його.
- Касові апарати: 8 моделей Unisystem, Exellio, ІКС та GERA/MG із пошуком, характеристиками й офіційними джерелами.
- Власні кейси й інструкції для касових апаратів: створення, редагування та імпорт TXT.
- Окремий редактор Python/C++, локальні проєкти, введення даних, вивід і Run/Stop.
- Python зі стандартною бібліотекою включено у Windows-збірку; для C++ потрібен установлений g++/clang++.
- Додавання інших мов через профілі інтерпретатора та команд компіляції.
- Код і конспекти зберігаються перед виходом; помилка збереження залишає чернетку відкритою.
- Оновлення встановлюється з MechaHub 0.6.0 і новіших без ручного видалення, зі збереженням даних.
