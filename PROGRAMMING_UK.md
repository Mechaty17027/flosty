# Власні проєкти в MechaHub

Розділ **«Програмування»** призначений для твоїх ідей. Нові файли зберігаються в `%APPDATA%\MechaHub\coding\projects`, окремо від коду MechaHub. Можна також відкривати власні UTF-8 файли та зберігати їх через «Зберегти як…».

## Python

1. Відкрий **«Програмування»** й обери **Python**.
2. Натисни **«Новий проєкт»** або просто введи код у редакторі:

   ```python
   name = input("Як тебе звати? ")
   print(f"Привіт, {name}!")
   ```

3. Натисни **«Запустити»**. Перед запуском код зберігається.
4. У вкладці **«Вивід»** введи ім’я в нижньому полі й натисни Enter або «Надіслати».
5. «Зупинити» завершує запущений проєкт. Перехід до іншого розділу зберігає код; при закритті хабу його власні активні процеси припиняються.

Windows-реліз включає окремий [Python 3.14.8 зі стандартною бібліотекою](https://www.python.org/downloads/release/python-3148/). Він не змінює встановлений у Windows Python. Для `pip`, Tkinter та сторонніх пакетів установи звичайний Python і обери його `python.exe` через **«Інструмент…» → «Вибрати виконуваний файл…»**. Особливості приватного runtime описано в [документації Python](https://docs.python.org/3/using/windows.html#the-embeddable-package).

## C++

Потрібен установлений g++ або clang++. Один варіант — [офіційна MSYS2](https://www.msys2.org/):

1. Установи MSYS2 й відкрий термінал **MSYS2 UCRT64**.
2. Виконай офіційну команду встановлення GCC:

   ```text
   pacman -S mingw-w64-ucrt-x86_64-gcc
   ```

3. У MechaHub обери **C++ → «Інструмент…» → «Вибрати виконуваний файл…»**. Для стандартного встановлення вкажи `C:\msys64\ucrt64\bin\g++.exe`.
4. Створи проєкт і натисни «Запустити». MechaHub спочатку компілює файл, а після успішної компіляції запускає результат. Помилки компілятора показуються у «Вивід».

```cpp
#include <iostream>

int main() {
    int a, b;
    std::cin >> a >> b;
    std::cout << "Sum: " << a + b << '\n';
    return 0;
}
```

Після запуску введи у нижньому полі `2 3` й натисни Enter. Папка компілятора додається до PATH лише для дочірніх процесів MechaHub; системний PATH не змінюється.

## Додати іншу мову

1. Установи потрібний інтерпретатор або компілятор.
2. Натисни **«+ Мова»**.
3. Укажи назву, розширення файла, виконувану програму та JSON-масив аргументів. Для JavaScript, наприклад: назва `JavaScript`, розширення `.js`, шлях до `node.exe`, аргументи `["{file}"]`.
4. За потреби додай команду компіляції як JSON-масив; для запуску її результату вкажи `{output}`.

`{file}` означає повний шлях файла, `{folder}` — його папку, `{output}` — файл результату компіляції. Кожен елемент масиву — окремий аргумент; пробіли в шляху не потребують додаткових лапок усередині елемента. Команди не є рядками PowerShell або CMD.

Профілі й вибрані інструменти зберігаються у `%APPDATA%\MechaHub\coding\languages.json`. Підсвічування синтаксису є для Python/C++; додані мови можна редагувати й запускати за своїм профілем. Власний код виконується з правами твого облікового запису Windows.
